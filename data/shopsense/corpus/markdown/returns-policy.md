# Kartway Returns and Refunds Policy

2.1. General Return Window: Unless specified otherwise, customers have 30 days from the date of delivery to initiate a return for a full refund.

2.2. Category-Specific Return Windows: The following categories have modified return windows:
    2.2.1. Electronics: 15 days from the date of delivery.
    2.2.2. Groceries: All grocery items are non-returnable due to perishable nature.
    2.2.3. Apparel: 45 days from the date of delivery.

2.3. Condition Requirements: To be eligible for a return, items must be in their original condition with all tags, accessories, and packaging intact. Items that are damaged, altered, or show signs of wear will not be accepted for return.

2.4. Return Shipping: 
    2.4.1. For items returned within the standard 30-day window, the customer is responsible for return shipping costs.
    2.4.2. For defective or incorrect items, Kartway will provide a pre-paid return shipping label.
    2.4.3. For items returned due to a change of mind, the customer is responsible for return shipping costs, except for apparel items, where Kartway will cover return shipping costs for the first return per customer per year.

2.5. Refund Processing Times: Refund processing times vary by payment method:
    2.5.1. Card payments: 5-7 business days from the date the return is received.
    2.5.2. Wallet payments: 24 hours from the date the return is received.
    2.5.3. Cash on Delivery (COD) payments: 10 business days from the date the return is received.

2.6. Partial Refunds for Opened Items: For items that are returned opened or used, the following partial refund schedule applies:
    2.6.1. Items with minimal signs of use (e.g., opened packaging): 80% of the original price.
    2.6.2. Items with moderate signs of use (e.g., minor scratches or wear): 50% of the original price.
    2.6.3. Items with significant signs of use (e.g., major damage or heavy wear): 0% of the original price.

2.7. Exceptions: The following items are exempt from the standard return policy:
    2.7.1. Custom or personalized items, which are non-returnable.
    2.7.2. Items purchased during special promotions or clearance sales, which are subject to a 15-day return window.

2.8. Approval and Processing: All returns are subject to approval by the Kartway returns team. The team, led by Returns Manager, Zara Saeed, will review each return request and may request additional information or documentation to process the return.
