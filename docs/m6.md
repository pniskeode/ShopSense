# M6 — Multi-agent team and MCP mock APIs

M6 handles a new chat message or a simulated email with one LangGraph Supervisor and four scoped workers:

- **Triage** classifies the request, sentiment, explicit order reference, and explicit INR claim.
- **Order-Actions** invokes only the local MCP tools. An `order_ref` is required for an operational lookup; when a `customer_ref` is also supplied, the MCP server verifies ownership before returning data. Order-only results exclude customer-profile fields and internal abuse flags.
- **Policy RAG** uses the existing M4 hybrid policy retrieval and preserves exact source citations.
- **Escalation Reviewer** independently records risk; deterministic code, not an LLM, decides whether a refund needs human approval.

The local FastMCP server exposes four read-only, customer-safe tools: order lookup, shipment tracking, refund inspection, and approved-refund-total calculation. It also exposes `shopsense://contracts/mock-api-v1`, a read-only contract resource. It does not expose filesystem operations, generic data enumeration, source-data writes, or the internal customer abuse flag.

Every case is checkpointed in `runtime/shopsense_m6.sqlite`. A simulated email uses `m6:email:<message_id>` as its idempotent case ID. A duplicate message reuses the saved state. Refund-only reviews pause for human `approve` or `reject`; approval records the workflow decision but never changes mock source data.

Examples after installing dependencies:

```cmd
python -m shopsense.agent.cli --m6-chat "Where is order KW-O-000123?" --customer-ref KW-C-11111
python -m shopsense.agent.cli --m6-email-file email.json
python -m shopsense.agent.cli --m6-resume --case-id m6:email:EMAIL-000123 --decision approve
```

The simulated email JSON requires a non-empty `body`. `customer_ref` is optional and enables memory/personalisation plus ownership validation when an order is referenced. `message_id` may be supplied by the sender; if omitted, the command-line simulation derives a stable ID using `SHOPSENSE_CASE_ID_SALT`. `subject` is optional.
